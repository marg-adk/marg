# SigNoz

Open-source APM on ClickHouse; traces, metrics and logs over OTLP.

```bash
OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
# SigNoz Cloud: OTEL_EXPORTER_OTLP_ENDPOINT=https://ingest.eu.signoz.cloud:443  OTEL_EXPORTER_OTLP_HEADERS=signoz-ingestion-key=…
```

Docs: https://signoz.io/docs/
