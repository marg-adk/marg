# Deepgram (voice notes)

The widget's mic sends a voice note; the transcript lands in the composer for review before it is sent. Language auto-detect and keyword boosting for your names.

```bash
DEEPGRAM_API_KEY=…
AGENT_STT_MODEL=nova-3
AGENT_STT_LANGUAGE=   # empty = auto-detect
AGENT_STT_KEYWORDS=Northwind,Contoso   # boost your vocabulary
```

Docs: https://developers.deepgram.com
